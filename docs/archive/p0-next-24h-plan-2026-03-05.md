In parallel with feature work, standardize local developer operations:

1. Add root-level `Makefile` with CI-aligned targets (`ci`, `test-ci`, `test-api`, `test-web`, `lint-shell`, `backend-smoke`, `frontend-smoke`, `format-check`).
2. Add `.editorconfig` baseline to keep whitespace/newline/indent defaults consistent.
3. Add local infra stack at `infra/dev/docker-compose.yml` (Postgres + Redis).
4. Add non-destructive environment scripts:
   - `scripts/dev/bootstrap.sh` (setup guidance + optional dependency installation hints)
   - `scripts/dev/check.sh` (environment and command readiness checks)
5. Add contributor-facing workflow doc `docs/CONTRIBUTING.md` and link it from README/docs index.

**Exit criteria for this lane:** fresh contributor can run local stack, export `DATABASE_URL` and `REDIS_URL`, then run `make ci` and the smoke checks without tribal knowledge.

## Operating rules
- **Docs-first for all sub-agent work**: read `docs/README.md`, `docs/architecture/plan.md`, `docs/execution/task-backlog.md`, and relevant domain docs before editing.
- Keep all claims research-grade (proxy estimates, not clinical decisions).
- Cache-first + graceful degradation for missing modalities.
- PostgreSQL is the source of truth for structured state (jobs/results/metadata).
