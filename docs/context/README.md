# Context Documents

This folder stores supporting context and research inputs used to shape the architecture.

## Files

- [`project-context.md`](project-context.md)
  - Living summary of scope, constraints, team split signals, UI priorities.

- [`deep-research-dataset-feasibility.md`](deep-research-dataset-feasibility.md)
  - Dataset feasibility analysis (why TCGA-LUAD, download and integration constraints).

- [`deep-research-pathology-mvp.md`](deep-research-pathology-mvp.md)
  - Pathology MVP implementation reference (tissue composition, infiltration proxy, heatmap).

- [`deep-research-transcriptomics-mvp.md`](deep-research-transcriptomics-mvp.md)
  - Transcriptomics MVP implementation reference (CYT/GEP/TIDE/evidence).

- [`chatgpt-roadmap.md`](chatgpt-roadmap.md)
  - Early implementation roadmap and hackathon sprint guidance.

- [`meeting-notes/`](meeting-notes/)
  - Original meeting summaries that informed product direction.

## Quick use

- Building pathology? Read pathology deep research first.
- Building transcriptomics? Read transcriptomics deep research first.
- Planning sprint scope? Read `project-context.md` then `../execution/task-backlog.md`.
